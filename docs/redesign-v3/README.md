Точную визуальную реализацию и извлечение палитры следует отложить до завершения и утверждения макета. Технический аудит репозитория можно начать.

## Правило реализации

Выбрано направление **Variant 3 с его цветовой концепцией и анимацией**. Финальный макет ещё разрабатывается; его конкретные параметры не зафиксированы. Цвета Variant 3.1 не утверждены. Текстовые описания и воспоминания о макете не задают точные HEX, шрифты, геометрию или ассеты. Не подбирать их «похоже» и не выдавать оценку за утверждённое значение.

Когда Алексей завершит и утвердит макет, положить его оригинальный файл в эту папку как `variant-3-approved.<ext>` с сохранением исходного формата; проверить, что это именно версия 3, и обновить manifest. Если вариантов экрана несколько, перечислить каждый файл отдельно. Затем можно снимать токены и делать визуальную реализацию.

До этого Codex может провести аудит, определить план и проверить существующий сайт, не меняя оформление. Содержимое спецификаций применимо к реально существующим элементам и к элементам, подтверждённым оригинальным макетом. Предложения из предыдущего чата (например, вкладка «Подбор» и переключатель темы) сами по себе не являются утверждёнными требованиями.

## Граница этого пакета

Пакет содержит документацию. HTML, CSS, JavaScript, ассеты рабочего сайта и публикация не менялись. Папка `docs/` в публичном GitHub Pages репозитории может стать общедоступной после включения в публикуемую ветку.
