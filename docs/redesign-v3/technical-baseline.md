# Техническая база сайта

Проверено 2026-09-30 по `origin/master` репозитория [kudashof/kudashof.github.io](https://github.com/kudashof/kudashof.github.io), commit `3965f0f`. Это исходное состояние перед дизайн-работой, а не проверка production.

## Факты из репозитория

- Статический одностраничный сайт: `index.html`, `main.css`, `fetchscript.js`, `script.js`, `img/noposter.jpg`.
- В `index.html` загружаются Bootstrap 4.4.1, `main.css` и `fetchscript.js`; `script.js` закомментирован.
- Реальный путь пользователя: открыть список популярных за неделю → ввести запрос и отправить форму → открыть карточку фильма/сериала → посмотреть сведения и доступные трейлеры.
- Результаты, сведения и ошибки вставляются в `#movies` через JavaScript. Данные и постеры запрашиваются у TMDB; трейлеры встраиваются с YouTube.
- Нет `package.json`, сборщика, конфигурации lint/test или автоматических тестов. Требование «запустить build/lint/tests» в handoff означает сначала проверить их наличие, а не создавать команды ради отчёта.
- В текущем дереве Git нет макета Variant 3, дизайн-ассетов, токенов темы или системы анимаций для редизайна.

## Важное для будущей реализации

- Сохранить поиск, выдачу, детали и трейлеры как действующие пользовательские сценарии, если Алексей отдельно не изменит scope.
- Описанные в дизайн-документах hero, много секций, мобильное меню, вкладка «Подбор» и переключатель темы не подтверждены текущим кодом. Сверить их с оригинальным Variant 3 и не добавлять по догадке.
- Данные TMDB сейчас вставляются в `innerHTML`, а ключ API находится в клиентском JavaScript. Перед выпуском редизайна оценить безопасность и способ работы с API; это отдельная техническая оценка, без изменения кода в данном пакете.
- Перед изменениями зафиксировать baseline в браузере: начальный список, поиск, пустой ввод, пустая выдача, ошибки сети, экран деталей и трейлер. Для визуальной приёмки нужен оригинал макета и сравнение скриншотов.
- Не считать отсутствие build/lint/tests успешным прохождением проверок. Указать «не предусмотрены репозиторием» и выполнить доступные ручные и синтаксические проверки по мере реализации.
