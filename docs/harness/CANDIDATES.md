# Кандидаты новых функций

Алексей 11 октября 2026 года разрешил описать эти функции для обсуждения. **Реализация, изменение навигации и публикация не утверждены.** Таблица показывает рекомендацию по исследованию, не план работ и не обязательство сделать всё в одном пакете. Кандидаты не входят в `manifest.json`; новый ID инициативы появляется только после решения о конкретном scope.

## Ближайшие кандидаты для решения после проверки проблемы

| ID | Проблема и минимальный срез | Данные, риск и условие решения |
| --- | --- | --- |
| CAND-001 — сохранённые подборы | Человек заново выставляет одинаковые фильтры. Сохранить небольшой набор параметров Подбора под локальным названием и применить повторно; результаты каждый раз брать из текущего каталога. | Локальные данные, без аккаунта и нового API. Ссылка передаёт только публичные фильтры, не личное название. Проверить повторяемость проблемы в [EXP-001](EXPERIMENTS.md), затем отдельно утвердить лимит, редактирование и удаление. |
| CAND-002 — выбор из «Моё» | В отложенном сложно выбрать одно название. Поиск/сортировка по уже сохранённым полям и один вариант из отложенных непросмотренных фильмов с возможностью запросить другой. | Не менять три независимые отметки автоматически; не выдавать случайный выбор за персональную рекомендацию. Существующий `updatedAt` означает последнее изменение, а не точную дату добавления. Проверить проблему в [EXP-001](EXPERIMENTS.md) и отдельно утвердить правило выбора. |

## Позже при подтверждённой необходимости

| ID | Возможный минимальный срез | Почему пока не реализуем |
| --- | --- | --- |
| CAND-003 — длительность | Ограничить фильмы по доступному времени, отдельно обрабатывать неизвестную длительность. | [DATA-002](RESEARCH.md) зафиксировал расхождение Discover и Details. Сначала [EXP-003](EXPERIMENTS.md); не обещать строгое «до 90 минут» по одному полю. Пилот «На один вечер» имеет другое обещание. |
| CAND-004 — сравнение | Явно выбранные 2–3 фильма рядом: год, жанр, длительность при наличии, оценка и число голосов. | На iPhone легко получить тесную раскладку; дополнительные детали грузить только для выбранных, не для всего каталога. Нужен сигнал, что люди действительно сравнивают варианты. |
| CAND-005 — короткий список ссылкой | Явно выбрать несколько названий и передать получателю один воспроизводимый URL. | Личные отметки и названия не включать автоматически. Проверить спрос на несколько вариантов; без комнат, голосования и синхронизации. |
| CAND-006 — следующая редакционная подборка | Одна новая ситуация выбора и несколько оригинальных пояснений. | Только после оценки пилота «На один вечер», с владельцем текста, проверенной длительностью/составом и датой следующего обзора. Не превращать в массовую CMS. |
| CAND-007 — сохранённая карточка офлайн | Явно сохранить ограниченное число метаданных для возврата без сети. | Сначала проверить нужность. Отдельно оценить хранение изображений, квоту и правила источника; не обещать офлайн-каталог или сохранность данных без резервной копии. |
| CAND-008 — люди кино | Перейти от понравившегося фильма к выбранному актёру или режиссёру. | Новые вызовы API и большое расширение навигации. Вернуться, если основной путь действительно часто упирается в этот вопрос. |

## Исключено из этого расширения

Аккаунты, серверная синхронизация, AI-чат, внешняя аналитика, платежи, совместные комнаты, полноценная CMS и массовое зеркало TMDB не являются кандидатами ближайшего пакета. Их цена, данные и режим поддержки требуют отдельного продуктового и технического решения. «Где смотреть» — уже существующая исследовательская инициатива [PROVIDERS-001](features/watch-providers.md), а не новая задача в этой таблице.
