## Решение

Алексей поручил выполнить все пункты [ТЗ](../../specs/people-search-filmography.md). Сценарий объединяет переход по актёру/режиссёру, поиск людей, живой поиск названий и дополнительные данные карточки. Публикация в production проверяется отдельно от ветки.

## Пользовательская проблема

Без перехода по человеку сложно найти другие его работы. При вводе части названия пользователь ждёт подсказок и обновления результатов без кнопки. Карточка не показывала в одном месте страну, дату, сертификат, жанры и понятную длительность; дополнительные факты и слоган отсутствовали.

## Гипотеза

Эти сведения сократят путь к следующему выбору. Измерения пользовательского эффекта пока нет.

## Scope

Страница человека с двумя вкладками, строгим разделением актёрской и режиссёрской работы, TV-фильтром ток-шоу, поиском однофамильцев по TMDB ID; подсказки и автоматическая выдача в общей строке; метаданные, слоган и раскрывающиеся дополнительные сведения полной карточки. Точная структура, правила данных, URL, доступность и проверки — в ТЗ.

## Не входит

Биографии, внешние аккаунты, серверная синхронизация, AI-перевод, поиск нескольких людей одновременно, финансовые выводы по бюджету и сборам.

## UX-сценарий

Найти человека по имени либо нажать на его фото в составе; переключить фильмы/сериалы и роль; открыть работу и вернуться. Для названий ввести «инте», увидеть подсказки и обновлённую выдачу, выбрать «Интерстеллар». В карточке проверить основные и дополнительные сведения.

## Данные и ограничения

Только TMDB и существующая статическая архитектура Pages. Фильмография — combined credits, поиск людей — search/person. Режиссура только job Director; дубли по ID объединяются. Details фильма/сериала используются для фактов, возрастные данные — из региональных списков. Пустые значения не подменяются догадками.

## Состояния

Загрузка, результат, пустая выдача, ошибка с повтором, отсутствующее фото, офлайн, уход во время запроса, прямой URL и Back/Forward. Полный перечень — в ТЗ.

## Критерии готовности

Два списка на странице человека, переходы и возврат, поиск без кнопки, сведения фильма/сериала на компьютере и телефоне, обе темы, доступная клавиатура, реальные ответы TMDB. Check/test и браузерные проверки; выпуск, публичный URL и физический телефон фиксируются отдельными фактами.

## Проверки

`npm run check`, `npm test`, локальный браузер с фильмом, сериалом, актёром, режиссёром, поиском имён и подсказками. Результаты и оставшиеся ограничения — в [EVIDENCE.md](../EVIDENCE.md#PEOPLE-001).

## Риски и откат

Неполнота TMDB, ток-шоу в TV-credits, разные региональные сертификаты, отсутствие длительности эпизода, увеличение запросов при вводе. Откат — revert отдельного PR и повышение версии PWA-кеша; данные «Моё» не удаляются.
