# Проверка ценности

Ни один из экспериментов ниже ещё не проведён. Это планы с вопросом и стоп-условием, а не доказательство спроса или согласие собирать пользовательские данные. Внешняя аналитика, сообщения участникам и передача личных списков требуют отдельного решения. Для первой проверки достаточно добровольного наблюдения и обезличенных заметок; удобная выборка не представляет всю аудиторию.

## Как фиксировать результат

Для каждого запуска записать: ID, утверждённый объём, дату, способ отбора участников/произведений, сценарий, знаменатель, исходные наблюдения без личных данных, исключения, результат, ограничения и решение Алексея. Нельзя заменять «пользователь открыл карточку» выводом «подбор помог выбрать фильм» или считать локальный счётчик браузера общим удержанием.

### EXP-001 — путь к решению

- Гипотеза: сохранённые параметры подбора и удобный выбор из «Моё» уменьшат повторную настройку и поиск среди отложенного.
- Предложенный метод: 5–8 добровольных участников проходят три задачи: выбрать фильм с неизвестным названием; выбрать из уже отложенного; выбрать при ограничении времени/жанра. Сначала наблюдать текущий продукт и обходные действия. Это качественный пилот, не статистический процент успеха аудитории.
- Сигналы: дошёл ли человек до конкретного выбора, где остановился, сколько вариантов пересмотрел, воспользовался ли сохранённым, подошёл ли выбор после просмотра. Записывать причины и неудобства, а не только число касаний.
- Условие продолжения: повторяющаяся проблема подтверждена и предложенный срез решает её без ущерба текущему пути. Если люди выбирают без затруднений или названия фильтров непонятны, пересмотреть решение до реализации.
- Связанные кандидаты: [CAND-001 и CAND-002](CANDIDATES.md). Ни контактов с участниками, ни новой функции это описание не запускает.

### EXP-002 — качество сведений «Где смотреть»

- Гипотеза: TMDB/JustWatch дают достаточно надёжные сведения для честного интерфейса по России.
- Предложенный метод: диагностическая основная выборка около 40 произведений с заранее закреплёнными фильмами/сериалами, старыми/новыми, российскими/международными примерами. Раздельно оценивать тип предложения: подписка, бесплатно, реклама, аренда, покупка. Точные элементы и правила замены определить до запросов.
- Основное доказательство: сверка с публичными официальными страницами площадок. Классы: `MATCH`, `FALSE_POSITIVE`, `FALSE_NEGATIVE`, `UNKNOWN`, `NETWORK_ERROR`; ошибки сети повторять и сохранять отдельно. Дополнительные находки за пределами основной выборки не менять её знаменатели.
- Решение отдельно для RU Movies и RU TV: достаточно данных / недостаточно данных / данные не подходят. Пороги точности и допустимая доля `UNKNOWN` пока не утверждены; 40 произведений не дают статистической оценки всего каталога.
- Связь: [DATA-001](RESEARCH.md), [PROVIDERS-001](features/watch-providers.md). До нового решения интерфейс не реализовывать.

### EXP-003 — честность фильтра длительности

- Гипотеза: можно дать пользователю понятное ограничение длительности без заметного числа неверных карточек и массовых запросов деталей.
- Предложенный метод: заранее составить небольшую диагностическую выборку с длительностью ниже, на и выше границы, с неизвестными данными и известным расхождением ID `1423191`. Сравнить Discover и Details, записать дату и язык каждого ответа.
- Критерий решения: правило показа и исключения сомнительных результатов понятно пользователю; число дополнительных запросов ограничено; пустые поля не превращаются в «0 минут». Если правило нельзя объяснить без ложного обещания, оставить длительность вне общего Подбора или использовать проверенную редакционную подборку.
- Связь: [DATA-002](RESEARCH.md), [CAND-003](CANDIDATES.md).
