## Реализуемая часть

- **LIB-PORT-001**: один UTF-8 JSON для всех трёх списков, локальный выбор файла, предпросмотр, объединение по умолчанию, подтверждаемая замена. Лимиты: 2 МБ и 500 записей. Ошибочный файл не меняет хранилище. Повторы объединяются по типу и ID; отметки складываются, метаданные берутся из более свежей записи. Импорт с нулём корректных записей ничего не меняет даже при замене. Проверяется, что между предпросмотром и записью список не изменился в другой вкладке. Перед заменой предлагается скачать текущие списки; предыдущие данные остаются в памяти и доступны для скачивания до обновления или закрытия страницы. Это временная страховка, не постоянная автоматическая копия.
- **EDIT-001**: один пилот в «Списках» с URL `?mode=lists&list=one-evening`. Восемь самостоятельных фильмов, оригинальные короткие пояснения, текущие постеры и оценки TMDB. Удалённые/недоступные ID не убирают остальные карточки; неполная загрузка явно обозначена с повтором. Содержимое `editorial.js` утверждено Алексеем 2026-10-07 и имеет `status: 'approved'`; ответственный — Алексей, следующая проверка — 2026-11-07. Пилот можно скрыть через `enabled: false` без изменения «Моё».
- **PROVIDERS-001**: исследование выполнено; блок не реализуется и не включается в выпуск, поскольку условие покрытия России не выполнено. Не подменять его поиском по сомнительным сервисам или другой страной.

## Проверки и единая приёмка

Автоматические проверки и факты локального браузера записываются ниже по мере выполнения. Ни один из них не заменяет физический iPhone или установленную PWA.

Исторический план приёмки до публикации (теперь выполняется одним проходом после разрешённого выпуска):

1. Утвердить состав, обещание и все восемь пояснений; назначить ответственного редактора и дату следующей проверки либо оставить пилот скрытым.
2. В Safari скачать «Моё», открыть файл на другом устройстве/чистом профиле, увидеть предпросмотр и объединить. Все три состояния, выбранная вкладка и URL сохраняются; повторный импорт не добавляет дубликаты.
3. На тестовых, не единственных личных данных проверить ошибочный файл, пустой файл и подтверждаемую замену; скачать предыдущую копию и восстановить её.
4. На iPhone открыть подборку по прямой ссылке, перейти в карточку, в рекомендацию, вернуться назад и вперёд, обновить страницу; сохранить прежнюю подборку и позицию. Проверить «Подбор → карточка → назад» с фильтрами и страницей.
5. В PWA с домашнего экрана проверить запуск обновлённой оболочки, экспорт и импорт без сети, отсутствие горизонтального скролла, читаемость обеих тем и работу клавиатуры.
6. Разрешение merge и публикации получено 2026-10-07. Проверить Pages/HTTPS и загруженную версию оболочки после выпуска. Статусы остаются `in_progress`, пока реальная приёмка не подтверждена; факт публикации не подменяет iPhone/PWA-проверку.

### Факты проверки

- Локальные автоматические тесты: 38 проходят; check и проверка пробелов проходят. Включены round trip, дедупликация, merge/replace, ограничения, неизвестные версии, опасные URL, повреждение, отказ хранилища, конкурентное изменение, частичная/пустая загрузка и отмена редакционных запросов, ссылки и полная согласованность версий offline-модулей.
- Локальный встроенный браузер: восемь реальных карточек и пояснения; редакционная ссылка → Амели → Back/Forward → refresh; возврат с фокусом на исходную карточку; ошибок консоли в этом сценарии нет.
- Импорт проверен через настоящий файловый выбор на отдельном тестовом origin, не на production. Неверный файл отклонён; корректный объединён; «Избранное» и URL сохранены. Найден и исправлен fallback жанров для импортированных карточек без жанров; после refresh такая карточка отображается.
- Подтверждение замены: кнопка отключена до checkbox, включается после него. Замена проверена unit-тестами; удаление списков через UI во время проверки не выполнялось.
- Подготовка экспортного Blob и сообщение интерфейса проверены, но событие скачивания не было возвращено встроенным браузером. Фактическое сохранение файла/перенос между устройствами остаётся в ручном gate, не объявляется выполненным.
- Узкая раскладка проверена на фактической CSS-ширине 381 px: `scrollWidth === clientWidth`. Физические Safari/iPhone/PWA, offline-перенос и ручная редакторская приёмка ещё не выполнены.
