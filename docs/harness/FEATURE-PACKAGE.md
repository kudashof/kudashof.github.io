# Единый пакет: перенос «Моё» и редакционный пилот

## Решение и границы

2026-10-07 Алексей ответил «делаем» на предложение:

> Утверждаю единый пакет: резервная копия «Моё», предложенная пилотная подборка с моим утверждением содержания и «Где смотреть» для России при достаточном покрытии. Один PR и одна общая ручная проверка, без публикации до отдельного разрешения.

Это разрешение на ограниченную реализацию и один PR, не на merge в `master` или публикацию. Для этого пакета правило «одна инициатива в PR» заменено одним согласованным пакетом. Автоматические и локальные браузерные проверки выполняются в процессе разработки; Алексей принимает весь пакет одним проходом.

Ветка: `codex/feature-package`. Базовая версия: `a4c4be1a0208df1124501956996caadd1714adea` (`master` после PR #9). Утверждённый Variant 3, поиск, Подбор, рекомендации, пиктограмма «Поделиться» и независимые состояния «Моё» сохраняются. Нет аккаунтов, сервера, аналитики, расходов или новых зависимостей.

## Реализуемая часть

- **LIB-PORT-001**: один UTF-8 JSON для всех трёх списков, локальный выбор файла, предпросмотр, объединение по умолчанию, подтверждаемая замена. Лимиты: 2 МБ и 500 записей. Ошибочный файл не меняет хранилище. Повторы объединяются по типу и ID; отметки складываются, метаданные берутся из более свежей записи. Импорт с нулём корректных записей ничего не меняет даже при замене. Проверяется, что между предпросмотром и записью список не изменился в другой вкладке. Перед заменой предлагается скачать текущие списки; предыдущие данные остаются в памяти и доступны для скачивания до обновления или закрытия страницы. Это временная страховка, не постоянная автоматическая копия.
- **EDIT-001**: один пилот в «Списках» с URL `?mode=lists&list=one-evening`. Восемь самостоятельных фильмов, оригинальные короткие пояснения, текущие постеры и оценки TMDB. Удалённые/недоступные ID не убирают остальные карточки; неполная загрузка явно обозначена с повтором. Содержимое `editorial.js` имеет `status: 'draft'`. Перед публикацией Алексей утверждает весь состав и пояснения; также нужно назначить редактора и дату следующей проверки (в конфиге пока явно не назначена). Утверждение разработки не заменяет утверждение содержания. При отсутствии редакционного решения пилот можно скрыть через `enabled: false` без изменения «Моё».
- **PROVIDERS-001**: исследование выполнено; блок не реализуется и не включается в выпуск, поскольку условие покрытия России не выполнено. Не подменять его поиском по сомнительным сервисам или другой страной.

Остальная выборка намеренно охватывает старые, популярные и российские произведения; это диагностическая выборка, не статистическая оценка всего каталога.

Итог: сведения в согласованных группах у **5 из 18** позиций; фильмы — 4 из 9, сериалы — 1 из 9; все четыре дополнительные новые позиции — без сведений. Вывод: для функции, рассчитанной на Россию, покрытие недостаточно. Это не означает, что остальные произведения нигде нельзя посмотреть. Непустые ответы не сверены с фактической доступностью сервисов, поскольку уже провален более ранний критерий покрытия; нельзя выдавать их за проверенную доступность или утверждать, что данные устарели.

Повторяемая безопасная проверка: `node scripts/check-provider-coverage.mjs` (читает только публичные метаданные, не выводит ключи). Возвращаться к UI провайдеров после нового исследования, подтверждения достаточного покрытия обоих типов и ручной сверки части непустых ответов.

По [официальной документации TMDB](https://developer.themoviedb.org/reference/movie-watch-providers) ответ содержит региональные сведения JustWatch и ссылку TMDB, а не полноценные deep links. Для использования данных обязательна видимая атрибуция JustWatch. [Документация TV](https://developer.themoviedb.org/reference/tv-series-watch-providers) задаёт тот же контракт. В этом пакете провайдеры не показаны, внешние запросы из пользовательской карточки не добавлены.

## Проверки и единая приёмка

Автоматические проверки и факты локального браузера записываются ниже по мере выполнения. Ни один из них не заменяет физический iPhone или установленную PWA.

Один проход Алексея перед разрешением публикации:

1. Утвердить состав, обещание и все восемь пояснений; назначить ответственного редактора и дату следующей проверки либо оставить пилот скрытым.
2. В Safari скачать «Моё», открыть файл на другом устройстве/чистом профиле, увидеть предпросмотр и объединить. Все три состояния, выбранная вкладка и URL сохраняются; повторный импорт не добавляет дубликаты.
3. На тестовых, не единственных личных данных проверить ошибочный файл, пустой файл и подтверждаемую замену; скачать предыдущую копию и восстановить её.
4. На iPhone открыть подборку по прямой ссылке, перейти в карточку, в рекомендацию, вернуться назад и вперёд, обновить страницу; сохранить прежнюю подборку и позицию. Проверить «Подбор → карточка → назад» с фильтрами и страницей.
5. В PWA с домашнего экрана проверить запуск обновлённой оболочки, экспорт и импорт без сети, отсутствие горизонтального скролла, читаемость обеих тем и работу клавиатуры.
6. Отдельно разрешить merge этого PR и публикацию. После выпуска проверить Pages/HTTPS и загруженную версию оболочки. До этого статусы остаются `in_progress`, не `verified`/`released`.

### Факты проверки

- Локальные автоматические тесты: 37 проходят; check и проверка пробелов проходят. Включены round trip, дедупликация, merge/replace, ограничения, неизвестные версии, опасные URL, повреждение, отказ хранилища, конкурентное изменение, частичная/пустая загрузка и отмена редакционных запросов, ссылки и полная согласованность версий offline-модулей.
- Локальный встроенный браузер: восемь реальных карточек и пояснения; редакционная ссылка → Амели → Back/Forward → refresh; возврат с фокусом на исходную карточку; ошибок консоли в этом сценарии нет.
- Импорт проверен через настоящий файловый выбор на отдельном тестовом origin, не на production. Неверный файл отклонён; корректный объединён; «Избранное» и URL сохранены. Найден и исправлен fallback жанров для импортированных карточек без жанров; после refresh такая карточка отображается.
- Подтверждение замены: кнопка отключена до checkbox, включается после него. Замена проверена unit-тестами; удаление списков через UI во время проверки не выполнялось.
- Подготовка экспортного Blob и сообщение интерфейса проверены, но событие скачивания не было возвращено встроенным браузером. Фактическое сохранение файла/перенос между устройствами остаётся в ручном gate, не объявляется выполненным.
- Узкая раскладка проверена на фактической CSS-ширине 381 px: `scrollWidth === clientWidth`. Физические Safari/iPhone/PWA, offline-перенос и ручная редакторская приёмка ещё не выполнены.
- Широкая раскладка: фактическая CSS-ширина 1581 px, `scrollWidth === clientWidth`; проверены светлая и тёмная темы. Все восемь пояснений привязаны к карточкам через `aria-describedby`; клавиатурный Tab переводит фокус на следующую карточку.
