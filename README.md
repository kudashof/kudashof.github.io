# Что посмотреть

Сайт для поиска фильмов и сериалов, подбора по нескольким условиям и просмотра готовых списков. Работает на данных [TMDB](https://www.themoviedb.org/) и публикуется на [GitHub Pages](https://kudashof.github.io/).

## Что можно сделать

- **Поиск:** найти фильм или сериал по названию; при необходимости ограничить тип результата.
- **Подбор:** выбрать фильмы или сериалы, один или несколько жанров, период, минимальную оценку и порядок результатов. Если выбрано несколько жанров, результат должен содержать **каждый** из них.
- **Списки:** открыть восемь готовых подборок TMDB: фильмы и сериалы в тренде, популярные и лучшие по оценкам, а также новые и ожидаемые фильмы.
- **Карточка:** посмотреть описание, жанры, оценку и доступный трейлер. Состояние поиска, подбора, списка и карточки отражается в адресе страницы, поэтому ссылкой можно поделиться.

Дизайн основан на выбранном для нового сайта направлении Variant 3: контрастная типографика, лаймовый акцент, светлая и тёмная темы. Есть адаптация под узкие экраны и настройку уменьшения движения.

## Запуск и проверка

Нужны браузер, Python 3 для локального сервера и Node.js для проверок. Сборка и установка npm-пакетов не требуются.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открой `http://127.0.0.1:4173/`. Данные каталога загружаются напрямую из TMDB, поэтому нужен доступ к его API.

```sh
npm run check
npm test
```

Публикация настроена из корня ветки `master` через GitHub Pages. Подробности о сценариях и принятых решениях — в [описании проекта](docs/PROJECT.md); о коде, данных, ограничениях и публикации — в [технических заметках](docs/TECHNICAL.md).
