# Что посмотреть

Статический сайт для поиска фильмов и сериалов и подбора по жанру, периоду и рейтингу. Каталог, карточки, описания, оценки и трейлеры загружаются из TMDB. Оформление основано на утверждённом Variant 3 с ярким лаймовым акцентом; поддерживаются светлая и тёмная темы, мобильные экраны и `prefers-reduced-motion`.

## Локальный preview

Из корня репозитория запусти `python3 -m http.server 4173 --bind 127.0.0.1` и открой `http://127.0.0.1:4173/`. Для работы каталога нужен доступ к TMDB. Сайт открывается напрямую из корня GitHub Pages; сборка и серверная часть не требуются.

## Проверки

`npm run check` проверяет синтаксис JavaScript, `npm test` запускает тесты адресного состояния, запросов и нормализации данных. Runtime-зависимостей npm нет.

Данные предоставлены TMDB. Этот сайт не одобрен и не сертифицирован TMDB.
